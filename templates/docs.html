StockClip AI Pro REST API

Welcome to the official documentation for the StockClip AI Video & Real Web Image Engine (V16.4). This backend microservice provides an asynchronous, highly optimized pipeline to fetch, analyze, and rank stock footage (from Pexels & Pixabay) and real web images (via SparkPicSearch) using deep learning models.

Asynchronous Architecture

This API does not return media immediately in the POST requests. Because the AI performs heavy operations (LLM query expansion, FAISS semantic matching, proxy image streaming, and CLIP visual scoring), the API returns a task_id. You must use the GET endpoint to poll for the final results.

Engine Architecture (V16.4)

To integrate seamlessly with this API, it is important to understand the two specialized pipelines running under the hood:

1. Stock Video Pipeline (Pexels + Pixabay)

  • Query Expansion: The engine uses openai/gpt-oss-120b (via Groq with automatic multi-key rotation) to expand your prompt into 6 cinematic variations while preserving core subjects.
  • Early Deduplication: Identical videos from Pexels and Pixabay are stripped immediately using async locks to save RAM and CPU cycles.
  • FAISS Semantic Mapping: paraphrase-multilingual-MiniLM-L12-v2 compares video metadata tags against your core intent.
  • CLIP Vision Scoring + OpenCV Fallback: clip-ViT-L-14 evaluates video thumbnails (or extracts live video frames via OpenCV if thumbnails fail) to compute an exact visual match score.

2. Real Web Image Pipeline (SparkPicSearch + Direct CLIP) NEW IN V16.4

  • Auto Multilingual Translation: Hindi or non-English queries are automatically translated to English so both web search and CLIP embeddings achieve maximum precision.
  • Zero LLM Bloat: Bypasses Groq 6-query expansion and FAISS text embeddings—executes a direct search against SparkPicSearch and streams the top 10 candidate images via proxy.
  • 15KB Integrity Filter & PIL Inspection: Automatically discards broken images or tracking pixels smaller than 15KB and extracts real pixel dimensions (width × height) in memory.
  • Direct CLIP-ViT-L-14 Ranking: Scores all valid images directly against your prompt/context using clip-ViT-L-14 and returns them sorted by visual confidence.

3. SQLite WAL Disk Caching

All successful video, image, and timeline searches are cached on disk (SQLite WAL mode) for 48 hours. Repeated queries return in <0.1s with zero external API calls.

Authentication

The frontend/gateway proxy is secured using a static API key. You must include this key in the header of every request.

Security Requirement

Header: x-api-key. If missing or incorrect, the server will return a strict 403 Forbidden response. Do not expose this key in public client-side code without a proxy.

Base URL: The API endpoints should be prefixed with your current host.

Search Stock Videos POST

/api/search

Submits a visual scene description to retrieve up to 12 AI-verified stock video clips. The backend spawns a background task in the ThreadPoolExecutor without blocking the server.

Request Body (JSON)

FieldTypeDescription
query * String The visual scene description in English or Hindi (e.g., "Cinematic dark forest rain").
orientation String Values: landscape (default) or portrait. Strict aspect ratio filtering is applied.
quality String Values: 1080 (default), 4k, 720, or any.

Example Request

cURL 
curl -X POST /api/search \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_SECRET_KEY" \
  -d '{
    "query": "A lone astronaut walking on Mars",
    "orientation": "landscape",
    "quality": "4k"
  }'

Response (202 Accepted)

You will receive a unique task_id. Save this to poll for status.

{
  "success": true,
  "task_id": "a1b2c3d4-5678-90ab-cdef-1234567890ab"
}

Search Real Web Images POST NEW

/api/images

Fetches real internet images via SparkPicSearch, streams up to 10 high-speed proxy candidates (>15KB), extracts exact resolutions via PIL, and ranks them directly using clip-ViT-L-14.

Request Body (JSON)

FieldTypeDescription
query * String The image search query in English or Hindi (e.g., "Ancient Kedarnath temple in snow").
orientation String Values: all (default), landscape (or 16:9), portrait (or 9:16), square (or 1:1).
page Integer Pagination index starting at 0 (default). Each page evaluates a fresh batch of up to 10 images.

Example Request

cURL 
curl -X POST /api/images \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_SECRET_KEY" \
  -d '{
    "query": "Ancient Kedarnath temple in snow",
    "orientation": "portrait",
    "page": 0
  }'

Response (202 Accepted)

{
  "success": true,
  "task_id": "f9e8d7c6-4321-11ef-9a00-0242ac120002"
}

Generate Video Timeline POST

/api/timeline

Takes a full paragraph or story script (in English or Hindi), splits it into logical sentences (up to 6 scenes), extracts core visual n-gram phrases using paraphrase-multilingual-MiniLM-L12-v2, and runs parallel video searches with cross-scene deduplication.

Request Body (JSON)

FieldTypeDescription
script * String Your full video script. Sentences shorter than 15 characters are ignored.
orientation String Values: landscape (default) or portrait.
quality String Values: 1080 (default), 4k, or any.

Example Request

JavaScript (Fetch)
const response = await fetch('/api/timeline', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': 'YOUR_SECRET_KEY'
  },
  body: JSON.stringify({
    script: "The Roman Empire was vast and powerful. Gladiators fought bravely inside the grand colosseum.",
    orientation: "portrait",
    quality: "1080"
  })
});
const data = await response.json();
console.log(data.task_id);

Data Schemas

1. The Clip Object (Stock Video)

The Engine normalizes video responses from both Pixabay and Pexels into a unified Clip object.

PropertyTypeDescription
idStringPrefixed with pex_ or pix_ to ensure global uniqueness.
typeStringAlways "video" for stock video clips.
download_urlStringDirect MP4 download link of the highest resolution available.
thumbnailStringJPG/PNG poster preview image for the video.
visual_scoreFloat0-100 percentage. Calculated by clip-ViT-L-14 matching frame pixels against the prompt text.
scoreIntegerFinal blended merit score (40% FAISS metadata score + 60% CLIP visual score).

2. The Image Object (Real Web Image)

Returned by POST /api/images after proxy validation (>15KB) and direct clip-ViT-L-14 scoring.

PropertyTypeDescription
idStringMD5-based unique identifier prefixed with img_.
sourceStringAlways "SparkPicSearch".
typeStringAlways "image".
urlStringOriginal source image URL on the host website.
proxy_url / download_urlStringCORS-safe, fast proxy stream URL via SparkPicSearch. Recommended for both <img src> rendering and downloading.
width / heightIntegerTrue pixel dimensions verified in memory via PIL.
ratioStringRequested aspect ratio filter (all, 16:9, 9:16, or 1:1).
visual_scoreFloatRaw CLIP cosine similarity percentage (typically 20.0% - 38.0% for strong matches).
scoreIntegerNormalized 0 - 100 score scaled relative to a 0.34 CLIP cosine ceiling.

Error Codes & Handling

Status CodeError TypeSolution
403 Forbidden Your x-api-key header is missing or incorrect.
400 / 422 Bad Request / Validation Error JSON body is missing required parameters (e.g., missing query or invalid types).
404 Not Found The task_id does not exist or has expired (exceeded 30 minutes TTL).
504 Gateway Timeout The backend HF Space is sleeping (cold start). Wait 5 seconds and retry the request.
